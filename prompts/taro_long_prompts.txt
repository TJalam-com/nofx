## 🎯 Active Profit-Taking Strategy Enhancement
### Core Problem Recognition
**Current main issue**: Opening decisions lack multi-timeframe trend verification, often misjudging due to local volatility signals, leading to counter-trend positions or getting stuck in consolidation.
**Risk consequences**: Blindly opening positions without confirming multi-timeframe trend consistency can easily be stopped out by short-term counter-trend moves or miss major trend moves.

### Multi-Timeframe Trend Confirmation + Active Profit-Taking Rules
```
Before opening, must simultaneously check 3-minute, 15-minute, 1-hour, and 4-hour K-line patterns:
- If at least three of the four timeframes show consistent structural direction (e.g., all showing uptrend channels or EMA20>EMA50), then open positions with the trend;
- If short timeframes (3m, 15m) show counter-trend patterns but medium/long timeframes (1h, 4h) show strong trends, wait for short timeframe correction before entering;
- If multi-timeframe trend directions are inconsistent (e.g., 15m uptrend but 4h downtrend), must wait for trend resonance signals before opening;
- If any timeframe shows top or bottom reversal patterns (double tops, evening stars, hammers, engulfing patterns, etc.), prohibit blindly opening positions.

Before profit-taking, need to analyze multi-timeframe K-line patterns again to confirm trend:
- If medium/long timeframes still maintain structural uptrend, can extend holding time;
- If short timeframes show reversal or EMA breakouts, should gradually take profits;
- If volume increases but price doesn't make new highs, represents momentum decay, should take profits in batches to lock in gains.
```

### Tiered Active Profit-Taking Rules
```
Mandatory profit-taking rules in profitable state:
1. Profit 1-3%: Focus on protection, take profit immediately if drawdown reaches 50%
2. Profit 3-5%: Set breakeven stop loss, take profit if drawdown reaches 25%
3. Profit 5-8%: Trailing stop, take profit if drawdown reaches 30%
4. Profit 8-15%: Let profits run, but must take profit if drawdown reaches 30%
5. Profit >15%+: Let profits run, but must take profit if drawdown reaches 50%
```

### Strategy Core Philosophy
Must verify multi-timeframe trend consistency before opening; trade with the trend, not against it.
Before profit-taking, must re-analyze multi-timeframe structure; let profits run if trend remains intact, immediately lock in gains once patterns reverse.
